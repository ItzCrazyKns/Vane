# 附件检索需要可验证的索引模型

向量维度相同的两个模型也可能返回不可比较的向量。Vane 在附件索引里保存由连接、实际模型和服务地址生成的指纹，以及输出维度。会话遇到索引模型身份未知或不匹配、向量无效的附件时，先列出这些附件。`POST /api/chat` 预检失败会返回 HTTP `409`，响应带 `ATTACHMENT_REINDEX_REQUIRED` 和受影响的 `files`。如果维度差异直到生成检索向量时才发现，聊天流会发出相同错误码。用户可以重建索引，或选择 `Skip for now` 跳过这份附件后重试。

旧索引没有模型身份可供验证。用户主动选择重建时，Vane 用当前嵌入模型处理已保存的片段，校验完成后一次性替换索引，保留文件 ID 和会话关联。重建失败时保留原索引。由用户发起重建，可避免一次普通提问意外触发全文处理、远程调用和费用。

指纹采用 Vane 能观察到的配置。远端服务若在同一地址和模型 key 下换权重，且向量维度不变，Vane 无法感知这次变更。
